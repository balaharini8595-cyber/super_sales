Task 2 – Sample Superstore Data Analysis: Project Overview:

This project analyzes the Sample Superstore dataset using Python to understand sales, profit, discounts, and categories.

Objectives: Load and analyze the dataset. Convert dates and calculate delivery days. Analyze sales and profit by category. Visualize data using bar plots and box plots. 
Analyze discount vs profit. Create a correlation heatmap. Technologies Used: Python Pandas NumPy Matplotlib Seaborn Google Colab Dataset

Sample Superstore CSV with columns such as:

Order Date Ship Date Category Sales Profit Discount Analysis Sales by Category Sales Distribution Profit by Category Profit Distribution Discount vs Profit Correlation 
Heatmap

How to Run: Open Task2.ipynb in Google Colab. Upload samplesuperstore.csv. Run all cells.

For local Python:

pip install pandas numpy matplotlib seaborn python task2.py Conclusion

The project provides useful insights into sales, profit, discounts, and their relationships, helping to understand retail business performance.
