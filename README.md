Super Store Data Analysis:

 Project Overview:

This project performs **Exploratory Data Analysis (EDA)** on the Super Store dataset using Python. The main aim is to understand sales, profit, discounts, product categories, and delivery time through data analysis and visualization.

 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

Dataset

The project uses the **Super Store dataset** containing information such as:

* Order Date
* Ship Date
* Category
* Sales
* Profit
* Discount

The dataset is loaded using Pandas.

Data Preprocessing

The following preprocessing steps are performed:

1. Load the Super Store CSV dataset.
2. Check the structure and basic information of the dataset.
3. Generate descriptive statistics.
4. Convert `Order Date` and `Ship Date` into date format.
5. Calculate the number of delivery days using order date and ship date.
6. Check for missing values.
7. Identify unique product categories.

Data Analysis and Visualization

The project performs the following analyses:

 1. Sales by Category

The total sales are grouped according to product category and displayed using a bar chart.

 2. Sales Distribution

A histogram is used to understand the distribution of sales values.

 3. Profit by Category

A bar chart is used to compare profit across different categories.

 4. Sales Distribution by Category

Sales values are visualized according to different product categories.

 5. Profit Distribution

A box plot is used to understand the distribution and variation of profit.

 6. Profit Variation Across Categories

A category-wise box plot is used to compare profit variation between categories.

 7. Impact of Discount on Profit

A scatter plot is created to study the relationship between discount and profit.

 8. Correlation Analysis

A correlation matrix is calculated for numerical columns and displayed using a heatmap.

 Project Objectives

* To understand the Super Store dataset.
* To analyze sales and profit.
* To compare sales and profit across categories.
* To study the impact of discounts on profit.
* To identify relationships between numerical variables.
* To visualize important patterns using graphs and charts.

 Conclusion

The project provides a basic understanding of the Super Store dataset through **Exploratory Data Analysis and visualization**. Different charts such as bar plots, histograms, box plots, scatter plots, and correlation heatmaps are used to identify useful patterns in sales, profit, discount, and category-wise performance.

 How to Run

1. Open the Python file or Google Colab notebook.
2. Install the required libraries if they are not already installed.
3. Upload the Super Store CSV dataset.
4. Run the Python cells step by step.
5. View the generated charts and analysis results.
